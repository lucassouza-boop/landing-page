# landing-page

Landing page comercial construída com [Vite](https://vite.dev) + React + TypeScript.

## Scripts

```bash
npm install      # instala dependências
npm run dev      # servidor de desenvolvimento
npm run build    # build de produção (dist/)
npm run preview  # pré-visualiza o build
npm run lint     # lint com oxlint
```

## Estrutura

```
src/
  components/   # componentes reutilizáveis (Header, Footer...)
  sections/     # seções da página (Hero, Features, CallToAction...)
  index.css     # estilos globais e tokens de design
```
